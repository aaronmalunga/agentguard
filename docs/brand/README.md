# Brand assets

| File | What it is |
|---|---|
| `banner.webp` | README banner, WebP (80 KB), 2560 × 840 (shown at 1280 × 420). Made 10 Nov from `banner-source.html` |
| `banner-source.html` | Source of the banner (HTML + CSS, site fonts embedded). Re-render with any headless browser at 2× scale |
| `banner-preview-1280.png` | Banner at its displayed size, for quick looks |
| `emblem-original.jpg` | Copy of the site's emblem (shield on its dark background), as used in the web app |
| `emblem-transparent.png` | The AgentGuard shield cut out of its grey background, transparent PNG (216 × 266) |

Colours and fonts match the live site (`src/agentguard/web/static/app.css`): paper `#121214`, accent `#d99a6c`,
Michroma for the name, Reddit Sans for text (both SIL Open Font Licence, see `src/agentguard/web/static/vendor/fonts/`).
The site itself still uses `src/agentguard/web/static/img/emblem.jpg`.
